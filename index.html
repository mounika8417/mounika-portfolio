Secure Multi-Site Network — OSPF, VLANs & Port Security
Goal: Simulate a real enterprise branch network with dynamic routing and traffic isolation

Designed a three-site topology in Cisco Packet Tracer connecting HQ, Branch A, and Branch B. Configured OSPF so routes propagate automatically across all sites. Segmented each site into three VLANs (Admin, Engineering, Guest) with Inter-VLAN Routing via Router-on-a-Stick. Applied port security on access switches to allow only one MAC per port, blocking rogue devices. Verified the full setup with ping, tracert, and show ip route to confirm route tables and VLAN isolation.

Key concepts demonstrated

OSPF neighbour relationships, 802.1Q trunking, inter-VLAN routing, and layer 2 switch security hardening.

CCNA · Packet Tracer · Completed
Enterprise Internet Gateway — DHCP, NAT & ACL Firewall
Goal: Build a gateway where hosts auto-get IPs and only authorised traffic exits to the internet

Built a simulated enterprise gateway with a DHCP server allocating IPs across three departments. Configured NAT overload (PAT) on the border router to translate all private RFC 1918 addresses to one public IP. Designed extended ACLs to block specific traffic flows — Guest VLAN cannot reach internal servers, while HTTP/HTTPS is permitted outbound. Tested every rule with targeted pings and verified NAT translations using show ip nat translations.

Key concepts demonstrated

Difference between static NAT, dynamic NAT, and PAT; ACL wildcard masks; reading NAT translation tables to debug connectivity issues.

Network Topology Mapper — Python + SNMP
Goal: Auto-discover and map all devices on a local network using Python

Built a Python script that performs ICMP ping sweeps to discover all live hosts on a subnet, then queries each device over SNMP to retrieve hostname, interface status, and neighbour data using CDP/LLDP MIBs. The script outputs a structured JSON report and generates a text-based topology diagram. Tested on a GNS3 virtual lab with simulated Cisco routers and switches. Final output is an auto-generated HTML report of the full discovered topology.

Key concepts demonstrated

Python socket programming, SNMP OIDs for network devices, pysnmp library usage, and parsing structured data into network reports.

Python · Flask · Completed
Network Health Monitor — Python + Flask Dashboard
Goal: Monitor device reachability, log results, and send alerts on failures automatically

Built a Python monitoring tool that reads a list of IP addresses from a config file, pings each host every 60 seconds, and logs status (up/down/latency) to a CSV file. When a device goes unreachable for two consecutive checks, the script sends an automated email alert via Python's smtplib. A live Flask web dashboard displays current device status in a browser in real time. Tested against a home router and Packet Tracer simulated devices.

Key concepts demonstrated

Python subprocess and os modules for ping execution, CSV file I/O for logging, smtplib for automated alerts, and Flask routing for a real-time web dashboard.
